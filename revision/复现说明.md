## 2　还原与计算

在仓库根目录执行：

```bash
python3 scripts/restore-jtl.py
python3 scripts/analyze.py
python3 revision/analysis/profile-existing.py
python3 revision/analysis/build-report.py
```

前两步恢复 34 个原始 JTL（含正式 24 轮、预热和试跑），校验 SHA-256，并按原有口径筛选 60 秒测量窗口。`profile-existing.py` 从原始 gzip 重新计算每轮秒级平均耗时、P80/P95/P99、40 ms 内完成比例及百分位曲线，保存 `revision/analysis/existing-load-profiles.json`。`build-report.py` 使用这些值与逐轮统计生成正文，不写入任何新测试结果。

八个 HTML 报告均从 `results/measured/{接口}-t{并发}-r1.jtl` 生成。示例：

```bash
export HEAP='-Xms64m -Xmx256m -XX:MaxMetaspaceSize=128m'
export JVM_ARGS='-Xss512k'
# 将 JMeter 路径改为本机安装位置；输出目录须尚不存在。
jmeter -g results/measured/ReadProduct-t50-r1.jtl \
  -q scripts/jmeter-user.properties \
  -o /tmp/lab3-read-t50-html
```

批量生成八档可执行 `JMETER_BIN=/实际路径/bin/jmeter python3 revision/analysis/generate-html.py`；已存在的目录保留，不覆盖。

JMeter 属性包含 `jmeter.reportgenerator.overall_granularity=1000` 与 100 万条百分位窗口。浏览器截图页面分别是 `content/pages/OverTime.html` 和 `content/pages/ResponseTimes.html`。截取完整曲线面板后，保持原尺寸上下排列即可得到报告中的阶段图。

## 3　查看完整 HTML

```bash
python3 -m http.server 8000
```

浏览器打开 `http://127.0.0.1:8000/revision/html/`，进入相应接口、并发档目录，即可查看 Dashboard、Over Time、Response Times 和其他原生图表。

## 4　重新导出 PDF

本机使用 Pandoc 将 Markdown 转为内嵌图片 HTML，再用 WeasyPrint 生成 PDF。样式文件为 `revision/analysis/sample-aligned.css`，导出脚本为 `revision/analysis/export-pdf.py`：

```bash
python3 revision/analysis/export-pdf.py
```

需要安装 Pandoc 与 WeasyPrint，并具备 Times New Roman、Songti SC、Heiti SC、Kaiti SC 字体；其他系统可替换为对应宋体、黑体和楷体。版式参照 PDF 样例的约 184 mm × 260 mm 单栏页面，字体采用本机近似字体，不宣称与 Windows 原字体完全相同。
